# Phase 01: Environment Preparation

## Step 1: Identify the Linux Environment

### Commands

```bash
cat /etc/os-release
uname -r
hostnamectl
```

### Command Descriptions

- `cat /etc/os-release`: Displays the Linux distribution name and version.
- `uname -r`: Displays the Linux kernel version.
- `hostnamectl`: Displays the system hostname and operating system information.
